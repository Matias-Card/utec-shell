# Archivos de inicialización, variables y expansiones

Este directorio contiene scripts relacionados con archivos de inicialización de Shell, variables, expansiones, aritmética de Shell y aliases.

- 0-alias: crea un alias llamado ls cuyo valor es rm -f *.

- 1-hello_you: imprime hello seguido del usuario actual de Linux.

- 2-path: añade /action al final de la variable PATH.
