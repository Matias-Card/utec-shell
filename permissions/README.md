# Permissions

Este proyecto contiene scripts para gestionar permisos de archivos y usuarios en Linux.

- 0-iam_betty: cambia el usuario actual al usuario betty.
- 1-who_am_i: muestra el nombre del usuario efectivo actual.
- 2-groups: muestra todos los grupos a los que pertenece el usuario actual.
- 3-new_owner: cambia el propietario del archivo hello al usuario betty.
- 4-empty: crea un archivo vacío llamado hell.
- 5-execute: añade permiso de ejecución al propietario del archivo heo.
- 6-multiple_permissions: añade ejecución al propietario y al grupo, y lectura a otros usuarios en el archivo hlo.
- 7-everybody: añade permiso de ejecución al propietario, al grupo y a los demás usuarios en el archivo hello.
